Scopul aplicației

Books on Web este o platformă pentru gestionarea lecturilor, marcarea favoritelor, urmărirea progresului și citirea în grup. Include integrare cu API-uri externe și export date.

Paletă de culori

Design minimalist, cu accent pe fundaluri pastelate și contrast ridicat pentru lizibilitate. Stil inspirat din NoDesign.dev și UI Faces.

Detalii de implementare

Frontend-ul este construit cu HTML, CSS și JavaScript pur. Backend-ul este implementat în Node.js cu stocare locală în SQLite. JWT este folosit pentru autentificare.

Baza de date

Se folosesc patru tabele principale: users, favorite, reading, progress. Fiecare înregistrează datele per utilizator folosind coloana username.

Tehnologii utilizate

  • Frontend: HTML5, CSS3, JavaScript
  • Backend: Node.js (http, fs, jwt, sqlite3)
  • Bază de date: SQLite 3
  • Autentificare: JWT
  • API-uri: Google Books API, Mockaroo

Securitate

Fiecare cerere către backend validează JWT-ul. Datele utilizatorului sunt separate și protejate per cont. Nu sunt expuse informații globale.

Funcționalități

  • Înregistrare și autentificare cu JWT a utilizatorilor si administatorului.
  • Pagina adminului unde acesta poate adauga carti pentru utilizatori.
  • Vizualizare și interacțiune cu cărțile disponibile introduse de administrator!
  • Integrare Google Books API pentru completarea automată a cartior pe care un utilizator doreste sa caute o carte.
  • Interfață prietenoasă, acolo unde utilizatorul poate sa citeasca carti, sa ofere recenzii si sa vada statistici pe baza recenziilor.
  • Statistici și recenzii pe baza recenziilor

Funcționalități individuale

index.html – Pagina principală

Aceasta este pagina principală. Utilizatorul poate accesa rapid funcționalitățile aplicației din meniul de navigare:

  • Cărți disponibile
  • Recenzii
  • Statistici
  • Logout
Pagina este personalizată în funcție de utilizatorul logat și îi oferă acces vizual rapid la toate zonele aplicației.

login.html și register.html – Autentificare / Înregistrare

register.html: Utilizatorul introduce numele, parola și confirmarea parolei. Dacă datele sunt valide, contul este creat și salvat în SQLite.

login.html: Utilizatorul se autentifică, primește un JWT și acesta este salvat în localStorage pentru autentificare ulterioară.

books.html – Cărți

Listă completă cu cărțile adăugate de admin. Utilizatorii pot căuta, filtra și marca o carte ca "Citește", "Favorite" sau "Citire în grup".

citire.html – Cărți de citit

Afișează cărțile marcate de utilizator pentru citire. Se poate seta progresul și elimina cartea din listă.

favorite.html – Cărți favorite

Vizualizare și gestionare cărți favorite personale. Se poate lansa citirea sau eliminarea unei cărți favorite.

progress.html – Progres

Se afișează vizual progresul per carte: pagini parcurse, procent, bară de progres. Datele sunt salvate per utilizator în baza SQLite.

Integrare Google Books API

Utilizatorul poate căuta cărți externe. Dacă cartea nu există, aplicația sugerează biblioteci reale folosind date JSON și Google Books API.
